# Jason Cao — Personal Site

A static personal website for college applications. Black-and-white, single page, built to host on GitHub Pages.

## Preview locally

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Edit before publishing

- Replace `YOUR.EMAIL@example.com` in `index.html` with a real address.
- Fill in SCY and LCM times in the athletics table (currently placeholders).
- Swap `favicon.svg` if you want a different icon.

## GitHub Pages

In the repository settings, enable Pages from the `main` branch, root folder. The site is `index.html` plus `style.css` — no build step.
